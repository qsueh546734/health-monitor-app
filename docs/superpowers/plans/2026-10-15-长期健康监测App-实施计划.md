# 长期健康监测 App 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个 Android App，通过 WiFi（ESP8266-01S）接收 STM32 的体温/心率/步数/水位数据，显示实时值、报警、历史曲线，并调用 DeepSeek 做健康分析。

**Architecture:** 原生 Java 单 Activity 多页面，零第三方依赖。所有不依赖 `android.*` 的逻辑（协议解析、状态机、模拟器、图表取数、密码哈希）抽成纯 Java 类，用裸 `javac` 秒级测试；网络层（TCP）与模拟器汇聚到同一个 `handleLine(String)`，因此没有硬件也能完整开发。构建走 GitHub Actions 云构建（本机无 Android SDK），交付走免凭据下载。

**Tech Stack:** Java 8 语法 / Android SDK 34（minSdk 24）/ `java.net.Socket` / `android.database.sqlite` / 自绘 `Canvas` 图表 / GitHub Actions（AGP 8.1.4 + Gradle 8.4 + JDK 17）

**Spec:** `docs/superpowers/specs/2026-10-15-长期健康监测App-设计文档.md`

## Global Constraints

- **零第三方依赖**：不用 AndroidX、Material、Kotlin、任何图表库。只用 Android 框架自带 API。理由：云构建失败面最小。
- **纯 Java 核心**：`Frame` / `Protocol` / `LineAssembler` / `AppState` / `Simulator` / `ChartData` / `Auth` **不得 import 任何 `android.*`**。这是能做到秒级本地测试的唯一前提。
- **协议按 spec §3 逐字实现**，不得改名、不得改字段顺序：
  - 帧以 `$` 开头、`\n` 结尾；字段 `,` 分隔、`=` 连接；`*` 后 2 位校验
  - 单帧 ≤ **128 字节**
  - 无效值发 `--`，**绝不发 0**
  - 小数固定 1 位
- **TCP 是字节流**：一次 `read()` 可能拿到半帧或两帧半，**必须**经 `LineAssembler` 累积后按 `\n` 切分。
- **隐式 ACK**：判据必须是**命令之后新到的帧**（记 `baselineRecv = recvCount`，要求 `recvCount > baselineRecv`）。否则残留状态会造成"命令没发出去却显示已确认"。
- **数据新鲜度**：超过 **3000 ms** 未更新，卡片必须置灰并显示"数据已 Xs 未更新"，**不得把旧值当实时值**。
- 报警**同一类 30 秒内只提示一次**。
- 数据库 `samples` 表上限 **50000 行**，超了删最旧。
- ESP 端命令（`WIFI` / `WIFIFORGET` / `WIFISTATUS`）由 ESP 拦截，STM32 看不到；`$I` 帧 App 也要处理。
- 端口默认 **8266**，AP 模式 IP 默认 **192.168.4.1**。
- **提交信息用中文**，格式 `type(scope): 摘要`。

## Review Focus

以下五类输入/条件，spec 隐含要求但没有任何单测天然覆盖 —— 它们最可能在实际使用时咬人。每条都必须在归属任务里有对应测试：

1. **SSID 或密码含特殊字符**（空格、`=`）：`iKUN 13` 是真实热点名，含空格。解析必须原样保留；含 `,` 属已知限制需在 UI 提示。
2. **序号大幅回退**（设备复位，如 3000 → 5）：必须重新同步，**不得虚报丢帧**。上一项目在此出过"丢 65277 帧"的假数据。
3. **`SW=0`（拨动开关关闭）**：帧里只有 `SEQ,SW,AL`，其余字段缺失。必须显示"系统已停止"且**不报警**，而不是把缺字段当 0 或显示旧值。
4. **半帧超时后紧跟新帧**（`$D,SEQ=12,BT=36` + 半秒后 `$D,SEQ=13,...`）：不得把两帧拼成一条垃圾记录。
5. **SQLite 达到 50000 行上限后的插入**：必须自动淘汰最旧且不抛异常、不阻塞主线程。

- [ ] **Step 4: 实现 LineAssembler**

```java
package com.example.healthmon;

/** 把字节流切成完整行。TCP 和串口都是字节流：一次读可能拿到半帧或两帧半。 */
public final class LineAssembler {
    public static final int MAX_BUFFERED = 4096;
    private final StringBuilder sb = new StringBuilder();

    /** 喂入一段字节。返回本次新产生的完整行（没有则返回 null，多行时逐次调用 poll）。 */
    public void feed(byte[] buf, int len) {
        for (int i = 0; i < len; i++) {
            char c = (char) (buf[i] & 0xFF);
            if (c == '\n') { sb.append('\n'); }
            else if (c != '\r') { sb.append(c); }   // 容错剥离 \r
            if (sb.length() > MAX_BUFFERED) sb.delete(0, sb.length() - MAX_BUFFERED);
        }
    }

    /** 取出下一整行（不含换行符）。没有完整行返回 null。 */
    public String poll() {
        int i = sb.indexOf("\n");
        if (i < 0) return null;
        String line = sb.substring(0, i);
        sb.delete(0, i + 1);
        return line;
    }
}
```

- [ ] **Step 9: 实现序号统计**

`Protocol` 增加 `public int dropped = 0;` 与 `noteSeq(int seq)`：
判定顺序（**顺序不能换**）：
1. 首次收帧 → 只记，不计
2. `seq == last` → 重复，不计
3. `seq == (last + 1) & 0xFFFF` → 正常，不计
4. **回退超过 100**（`(last - seq) & 0xFFFF` 很大）→ 视为设备复位，重新同步，**不计**
5. 其余 → `dropped += ((seq - last - 1) & 0xFFFF)`

```java
package com.example.healthmon;

public final class AppState {
    public static final long STALE_FRAME_MS = 3000;
    public static final long ALERT_REPEAT_MS = 30000;

    public Frame last;
    public long recvCount = 0;
    private long lastFrameMs = 0;
    private long cmdBaseline = -1;
    private double cmdWantBt = Double.NaN;
    private int cmdWantHr = -1, cmdWantWLow = -1, cmdWantPmode = -1;
    private final java.util.HashMap<Integer, Long> lastAlertAt = new java.util.HashMap<>();

    public void onFrame(Frame f) { last = f; recvCount++; }

    /** 记录帧到达时刻（由调用方提供，便于测试注入） */
    public void noteFrameTime(long nowMs) { lastFrameMs = nowMs; }

    public boolean isStale(long nowMs) {
        return last != null && lastFrameMs > 0 && (nowMs - lastFrameMs) > STALE_FRAME_MS;
    }

    /** 发命令前调用：记下基线收帧数 —— 没有这个基线就会出现"没发出去却显示已确认" */
    public void markCommandSent(double wantBt) {
        cmdBaseline = recvCount; cmdWantBt = wantBt;
        cmdWantHr = -1; cmdWantWLow = -1; cmdWantPmode = -1;
    }
    public void markCommandSentHr(int wantHr) {
        cmdBaseline = recvCount; cmdWantHr = wantHr;
        cmdWantBt = Double.NaN; cmdWantWLow = -1; cmdWantPmode = -1;
    }
    public void markCommandSentWater(int wantLow) {
        cmdBaseline = recvCount; cmdWantWLow = wantLow;
        cmdWantBt = Double.NaN; cmdWantHr = -1; cmdWantPmode = -1;
    }
    public void markCommandSentPumpMode(int wantPmode) {
        cmdBaseline = recvCount; cmdWantPmode = wantPmode;
        cmdWantBt = Double.NaN; cmdWantHr = -1; cmdWantWLow = -1;
    }

    /** 只有【命令之后新到的帧】才允许判定确认 */
    public boolean isConfirmed(Frame f) {
        if (cmdBaseline < 0 || f == null) return false;
        if (recvCount <= cmdBaseline) return false;          // 关键：先看是否有新帧
        if (!Double.isNaN(cmdWantBt)) return !Double.isNaN(f.btHi) && Math.abs(f.btHi - cmdWantBt) < 0.05;
        if (cmdWantHr >= 0) return f.hrHi == cmdWantHr;
        if (cmdWantWLow >= 0) return f.wLow == cmdWantWLow;
        if (cmdWantPmode >= 0) return f.pmode == cmdWantPmode;
        return false;
    }
    public void clearCommand() { cmdBaseline = -1; }

    public boolean isSystemOff() { return last != null && last.sw == 0; }

    /** 同类报警 30 秒内只提示一次，否则 1Hz 数据会刷屏 */
    public boolean shouldAlert(int alBit, long nowMs) {
        if ((last == null ? 0 : last.al & alBit) == 0 && alBit != 0) {
            // 具体位是否触发由调用方先判断；这里只负责节流
        }
        Long prev = lastAlertAt.get(alBit);
        if (prev != null && nowMs - prev < ALERT_REPEAT_MS) return false;
        lastAlertAt.put(alBit, nowMs);
        return true;
    }

    public void reset() {
        last = null; recvCount = 0; lastFrameMs = 0;
        cmdBaseline = -1; cmdWantBt = Double.NaN; cmdWantHr = -1; cmdWantWLow = -1; cmdWantPmode = -1;
        lastAlertAt.clear();
    }
}
```

```java
package com.example.healthmon;

import java.util.ArrayList;
import java.util.List;

public final class ChartData {
    private ChartData() {}

    /** 等间隔抽稀，但【首尾一定保留】—— 否则曲线看起来像被截断了 */
    public static List<long[]> downsample(List<long[]> pts, int maxPoints) {
        List<long[]> out = new ArrayList<>();
        if (pts == null || pts.isEmpty()) return out;
        int n = pts.size();
        if (maxPoints <= 0 || n <= maxPoints) { out.addAll(pts); return out; }
        double step = (double) (n - 1) / (maxPoints - 1);
        for (int i = 0; i < maxPoints; i++) {
            int idx = (int) Math.round(i * step);
            if (idx >= n) idx = n - 1;
            out.add(pts.get(idx));
        }
        return out;
    }

    public static long[] range(List<long[]> pts) {
        if (pts == null || pts.isEmpty()) return new long[]{0, 0, 0, 0};
        long minV = Long.MAX_VALUE, maxV = Long.MIN_VALUE, minT = Long.MAX_VALUE, maxT = Long.MIN_VALUE;
        for (long[] p : pts) {
            if (p[1] < minV) minV = p[1];
            if (p[1] > maxV) maxV = p[1];
            if (p[0] < minT) minT = p[0];
            if (p[0] > maxT) maxT = p[0];
        }
        return new long[]{minV, maxV, minT, maxT};
    }
}
```
